## Getting Started

### Prerequisites

- A modern web browser
- Local web server (optional, for development)

### Installation

1. Clone or download the repository
2. Open `index.html` in a web browser
3. For development with live reload, use a local server:

   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js
   npx serve .

   # Using PHP
   php -S localhost:8000
   ```

### File Structure

```
portfolio/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
├── README.md           # Project documentation
└── sw.js              # Service worker (optional)
```

## Customization

### Adding New Projects

1. Open `index.html`
2. Find the projects grid section
3. Add a new project card following the existing structure
4. Update the project links and descriptions

### Modifying Skills

1. Open `index.html`
2. Locate the skills section
3. Update skill names and percentages
4. The progress bars will automatically adjust

### Changing Colors and Themes

1. Open `styles.css`
2. Modify the CSS custom properties in `:root`
3. Update the dark theme variables in `[data-theme="dark"]`
